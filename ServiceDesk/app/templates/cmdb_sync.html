What the sync does

  • Reads Entra-joined and hybrid-joined devices from Microsoft Graph (no Intune needed).
  • New devices are added as configuration items; a device whose name matches an item you imported is linked rather than duplicated.
  • Name, OS/version, last sign-in and the registered owner are updated each run, so devices show up under each person's My devices. Manufacturer/model are only filled when blank; your other fields (asset tag, location, support group, warranty…) are never touched.
  • Devices disabled in Entra are marked In Maintenance.

Setup

  1. Use the same app registration as single sign-on (or a separate one).
  2. API permissions → Add a permission → Microsoft Graph → Application permissions: Device.Read.All and User.Read.All, then Grant admin consent.
  3. Set ENTRA_TENANT_ID, ENTRA_CLIENT_ID, ENTRA_CLIENT_SECRET and restart.
