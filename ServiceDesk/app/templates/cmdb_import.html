How it works

  • Columns: {{ columns|join(', ') }}. Only name and type are required.
  • type: {% for t in CIType %}{{ t.value }}{{ ', ' if not loop.last }}{% endfor %}. status: {% for s in CIStatus %}{{ s.value }}{{ ', ' if not loop.last }}{% endfor %} (default in_use).
  • Rows update an existing item when the asset_tag matches, otherwise the serial_number; applications and services without either match on name. Everything else is created new.
  • Blank cells never erase existing values, so you can re-import a partial sheet safely.
  • assigned_to_email links the device to a user so it appears under their My devices. {% if sso_providers %}Unknown emails get an SSO account that links when the person first signs in.{% else %}Unknown emails are reported and left unassigned.{% endif %}
  • support_group is matched by name and created if it doesn't exist. Add members under Groups.
  • Dates: YYYY-MM-DD (also accepts MM/DD/YYYY). Exports from Excel (UTF-8 or Windows encoding) work.
